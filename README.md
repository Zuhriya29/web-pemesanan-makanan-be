# Food Ordering Backend API

Backend service for a Food Ordering Web Application built with Laravel and PostgreSQL. This project provides RESTful APIs for user authentication, menu management, order processing, and QR Code-based order validation.

## Features

* RESTful API Architecture
* User Registration and Login
* Google OAuth Authentication
* Email Verification
* Password Reset via Email
* Authentication and Authorization
* Menu Management
* Shopping Cart Management
* Order Processing
* QR Code Generation
* QR Code Validation
* Protected API Routes

## Tech Stack

* Laravel
* PostgreSQL
* Laravel Sanctum
* Google OAuth
* REST API

## API Modules

### Authentication

* Register
* Login
* Google OAuth Login
* Email Verification
* Password Reset

### Menu Management

* Create Menu
* Update Menu
* Delete Menu
* View Menu

### Order Management

* Create Order
* Update Order Status
* View Order History

### QR Code Validation

* Generate QR Code
* Validate QR Code
* Time-Based QR Code Regeneration

## Database

PostgreSQL is used to store:

* Users
* Menus
* Orders
* Order Details
* Carts
* Carts Details
* Authentication Data
